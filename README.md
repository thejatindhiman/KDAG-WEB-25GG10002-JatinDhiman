# KDAG Knowledge Quiz

Hi! I'm Jatin Dhiman, currently pursuing Applied Geology at IIT Kharagpur. I have a strong passion for web development and love creating interactive websites. This quiz project combines my interest in technology with the amazing work KDAG does in data analytics. It's been a great learning experience building this with HTML, CSS, and JavaScript!

A simple quiz website for KDAG (Kharagpur Data Analytics Group) made with HTML, CSS and JavaScript.

## What it does
- Shows 5 multiple choice questions about data analytics
- You can go back to previous questions 
- Submit button appears after answering all questions
- Shows your score and correct answers at the end

## How to use
1. Open the HTML file in your browser
2. Answer the questions by clicking on options
3. Use Previous/Next buttons to navigate
4. Click Submit on the last question to see results

## Files
- `index.html` - Main quiz page
- `style.css` - Makes it look good
- `script.js` - Makes it work

## Features
- 5 questions about KDAG and data science
- Navigation buttons
- Score calculation
- Answer review
- Simple design
